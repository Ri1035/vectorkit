# 自研矢量化方案（vectorkit 开源方案集）

> 本项目的后处理管线包含 6 项**自研算法**，均为纯前端实现、零额外依赖，
> 可作为独立方案复用于其他位图转矢量工具。
> 开源路线调研结论：**VTracer 已是开源最佳**（Rust / O(n) / 堆叠策略），
> 但它与所有描摹引擎都不做的事情——**几何基元拟合、边界一致化、曲率自适应简化、
> 内部元素保护**——正是本方案集要补的空白。

---

## 方案 A：曲率自适应抽稀（`dpKeepRingPointsAdaptive`）

**问题**：D-P 用单一容差时，"保细节"与"减节点"互相矛盾。
**做法**：逐点自适应容差——偏转角 ≤14° 视为平坦点（容差 ×4、容易被简化掉）；
细节点容差不变；判定改为「偏差是否超过**该点**的容差」。
**关键设计**：不按曲率"切子段"（切段会产生强制保留的边界点，节点反而增加）。
**效果**：节点 **−12~16%**，细节与色块数不变。

## 方案 B：相邻色块边界一致化（`snapAdjacentBoundaries`）

**问题**：相邻色块各自独立拟合边界 → 公共边界错位 0.5–2px → 碎边/双线。
**做法**：全局锚点放入**空间散列**，跨路径且距离 ≤1.2px 的锚点**吸附到中点**；
控制点同步平移保持切线；单点位移上限 2px 防误吸附。
**效果**：Baby Happy 修正 **168 处**错位，色块/节点数几乎不变（不破坏结构）。

## 方案 C：对比度感知的碎块清理（`isHighContrastDetail`）

**问题**：碎块清理只按**面积**删——面积无法区分"设计细节"与"压缩噪点"。
**做法**：面积过小的元素，若与周围环境色差 ≥60（高对比）则保留（细节），否则删除（噪点）。
**性质**：防御性改进（对噪点多的图才有可见效果）。

## 方案 D：等半径统一（`unifyEqualRadiiInSvg`）

**问题**：设计稿里成组的圆点应同尺寸，描摹后半径有 ±10% 抖动。
**做法**：识别 `M+4C+Z` 拟合形状 → 半径聚类（≤18%）→ 每组 ≥3 个统一为平均半径。
**关键坑**：必须**按子路径拆分**识别（同色合并会把多个圆并成 CompoundPath）。

## 方案 E：内部元素保护（`protectInteriorElements`）⭐ 最有价值

**问题**：引擎把「与画布底色同色、被前景包围的小元素」（眼白/高光/内部白点）当作背景处理而丢失。
**前代失败方案**：改**背景**色 → 引擎额外描摹背景层 → 抗锯齿边缘变成沿轮廓的**碎路径**（否决）。
**本方案**：只微调**前景元素**颜色（背景完全不动）→ 元素与背景区分 → 被保留；
输出时按「位置 + 颜色」还原原色。
**为什么安全**：不产生碎轮廓（背景未变）；**不凭空添加元素**（只让引擎保留原图已有元素）。
**关键参数**：偏移量必须**明显大于**引擎的 `layerDifference`（默认 16）——16 恰好临界会被吞，用 28。

## 方案 F：轮廓低通平滑（`smoothContourPoints`）

**问题**：抗锯齿过渡像素让边界带 1–2px 高频起伏（长边的"毛边/碎边"），
全曲线拟合只能平滑低曲率点，无法消除点间距级别的抖动。
**做法**：对重采样后的点列做**曲率保护的低通滤波**——
只在低曲率区（转角 <25°）用邻域加权平均修正坐标；角点与含角点的邻域原样跳过。
**性质**：抹平毛边而不磨损细节与硬边。

## 组合使用建议

| 场景 | 推荐组合 |
|---|---|
| 扁平插画 / 贴纸 | A + B + E（+ F）|
| 节点敏感（CDR 卡顿）| A + B |
| 噪点多的压缩图 | C + A + B |
| 成组圆点的设计稿 | D + A + B |
