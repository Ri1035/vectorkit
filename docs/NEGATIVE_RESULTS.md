## 四、交接实验的工程坑（复跑时注意）

1. Node 里 vendor 的 wasm：`fetch` 不支持 `file://` → import 前 patch `globalThis.fetch` 走 `fs.readFile`
2. PowerShell 传 JSON：引号被吃掉 → options 写文件，不走命令行
3. PowerShell 不支持 heredoc → 写成 `.py` 文件再跑
4. 不要用 `Set-Content -Encoding utf8` 重写 Python 源码（中文注释会变成私用区字符）
5. PIL 保存 `.raw` 会报 `unknown file extension` → `open(path,'wb').write(im.tobytes())`
