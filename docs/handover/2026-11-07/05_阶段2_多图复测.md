## 四、结论

### 4.1 交接数字已复现（bc）

A 32.88 / B 33.29 / B2 33.28，与交接书 32.88 / 33.29 / 33.34 一致（B2 差 0.06 dB）。
**「在 polygon 上重拟合得不到提升」在复测中成立。**

### 4.2 B2（重拟合）四图全败

| 图 | B2 − B |
|---|---|
| bc | −0.01 dB（持平） |
| h | +0.09 dB（但 edgeCorr −0.026） |
| x | **−1.81 dB**，并新增 **1129** 个白缝像素（A/B 均为 0） |
| xrk | **−2.03 dB** |

→ **阶段 3 的 B2 精度档不批准**（预登记条件要求至少两类 PSNR ≥ spline +0.30，B2 一类都没达到）。

### 4.3 新发现：polygon 原样（B）的优势**依赖图像类型**

| 图 | B − A | 判定 |
|---|---|---|
| bc（扁平 + 手写） | **+0.41** | ✓ B 更好 |
| x（扁平色块） | **+0.48** | ✓ B 更好 |
| h（细线稿） | −0.25 | ✗ A 更好 |
| xrk（颗粒纹理） | **−2.35** | ✗ A 明显更好 |

**解释（与交接书第 7 节“已知未验证项”一致）**：
- 边界本身干净（扁平色块）时，`polygon` 的像素精确边界优于 `spline` 的平滑（平滑=推离真值）；
- 边界本身有噪声（纹理/做旧）或极细（线稿）时，`spline` 的平滑能抑制噪声与阶梯，反而更好。

→ **不存在“一律更好”的引擎模式**；交接结论“几何后处理无效”应细化为
**“对干净边界无效且有害；对有噪声边界方向可能反转”**。

### 4.4 cutout 共享边确认存在，逐路径重拟合必然撕边

`shared_edges.py` 统计（polygon 输出中被 ≥2 个子路径共用的边）：

| 图 | 子路径 | 边数 | 共享边 | 占比 |
|---|---|---|---|---|
| bc | 96 | 2434 | 2335 | **95.9%** |
| h | 291 | 6206 | 5720 | **92.2%** |
| x | 83 | 1603 | 1508 | **94.1%** |
| xrk | 171 | 4453 | 4115 | **92.4%** |

重拟合后锚点重合率：`x` 99.7% → **96.1%**，`xrk` 99.7% → **97.0%**；
两侧控制点由各自邻点决定，必然不同 → 公共边两侧曲线不再重合。

**实测后果**：`x` 的 B2 白缝 **0 → 1129 像素**（A/B 均为 0）。这就是 N8 所述撕裂。

> 结论：任何逐路径改写几何的方案，在 cutout 下**必须先建共享边对应表并两侧同步拟合**，
> 否则白缝必然出现。

## 五、指标缺陷（必须登记）

`perceptual.js` 的 `ssimEdge` 在本批图出现**不可能值**：

| 图 | 方案 | ssimEdge.mean |
|---|---|---|
| h | B2 | **1.96951** |
| xrk | B | **11.03204** |

SSIM 均值理论上限为 1。根因推测：梯度图归一化尺度取自参考图 99 百分位，
当该尺度接近 0（参考图梯度极弱区主导）时会放大噪声。**本轮不使用这两个数字下结论**；
后续需在 `ssimEdge` 内对 `mean` 做钳制或加尺度下限（记入待办，本轮不改代码）。

`jagEnergy` 的方向也需谨慎：`h` / `xrk` 的输出 jag **低于参考图**（−33 / −2.6），
说明描摹结果比带纹理的原图更“干净”，这既可能是去噪也可能是细节丢失，**不能直接解读为好**。
