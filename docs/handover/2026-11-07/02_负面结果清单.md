# 交接书 02 · 负面结果清单（别重复做）

> 每条都有本轮或项目既有实测支撑。**在动手前先读这一页**，能省掉几周的弯路。

---

## N1. ❌ 在 VTracer 输出上做几何平滑 / 变分优化

**证据**：本轮 C 系列 4 组权重 + 1 组零权重对照

| 权重（w_len / w_prior） | PSNR |
|---|---|
| 不优化（B2） | **33.34** |
| w=0（对照，产物逐字节相同） | **33.34** |
| 0.1/0.05 · 0.01 | 32.04 |
| 0.5/0.2 · 0.05 | 31.97 |
| 1/0.5 · 0.1 | 31.69 |
| 5/0.5 · 1 | 31.99 |

**原因**：VTracer 的 polygon 点是像素精确边界；平滑=把点推离真值，没有更准的目标时必亏。

**唯一例外**：如果输入是**有噪声的边界**（照片分割、扫描件），平滑可能有益——但 VTracer 的输出不是这种。

## N2. ❌ 逐点亚像素重定位

**证据**：
- 项目 v5.2：只 5 个锚点合格，收益 ≈0.00 dB
- 本轮 D：沿法线找 50% 亮度交叉，**81% 的点（3250/4011）被判"可移动"**，联合优化后 **30.41 dB**（−2.93）

**原因**：
1. 法线估计粗糙（相邻两点连线，对折线噪声敏感）
2. 50% 亮度中点 ≠ 真实几何边界（尤其在有阴影/渐变时）
3. 扁平插画的边界本来就是锐利的，"亚像素"没有信息可挖

## N3. ❌ 用 `simplify` 压体积

项目实测：`simplify 1` → MSE +7.4%。本轮容差扫描复现同一趋势：

| rdp eps | 段数 | PSNR |
|---|---|---|
| 0.35 | 4006 | 33.34 |
| 0.8 | 2759 | 33.01 |
| 1.5 | 1830 | 32.03 |
| 2.5 | 1334 | 29.50 |

且用户已明确"体积不设约束"。**不要再为体积牺牲精度**。

---

## N4. ❌ 用降噪换平滑

项目 v5.3：去噪 14→8，PSNR +2.86 dB，但用户反馈"边缘锯齿明显了"。
降噪是全局的，会连真细节一起抹；边界平滑只能在边界局部做，且需死区。

---

## N5. ❌ 重写 Bézier 拟合器

- 项目 `bezierfit.js`：Schneider + 牛顿-拉夫森重参数化 + 角点断点，已经完善
- 本轮自研 Python 版（`rdp + 手柄`）：4006 段才 33.34；Schneider 版因**未做角点分段**崩到 17.56 dB

**结论**：`bezierfit.js` 不比 VM 差，换掉是退步。若要在 Python/其他语言复刻，**必须照抄它的角点分段逻辑**，不要直接对闭合点列跑 Schneider。

## N6. ❌ 换引擎（ImageTracer / Potrace）追精度

项目已有结论：ImageTracer 路径数爆炸（16 色 2.9 万条 / 5.8 MB），Potrace 只适合黑白。
本轮未重测，沿用项目结论。

## N7. ⚠️ 提高描摹分辨率（收益递减，但仍是当前最有效的一招）

项目实测：1024 → 2048 得 **+3.15 dB**，但仍差 4.8 dB。
本轮未重测（1280 原生）。若要用，注意 `MAX_SIDE 2400` 与 8M 像素预算，
且 14.7M 像素时 VTracer 输出会退化（大面积白色覆盖）。

---

## N8. ❌ 在 `cutout` 模式下做任何逐路径几何改动

项目 `app.js:1053` 已写明：cutout 下相邻面共用边界，逐路径改几何会撕开（实测 MSE ×46）。
本轮实验**只用 polygon 的独立路径**，未触发这个问题；若要在生产链路上做几何处理，
**必须先建共享边对应表**（见 `03_VM算法参考.md` 第 4 节）。

---

## N9. ❌ 追求"和 VM 一样"的 PSNR

VM 的 39.06 dB 是"像素级复刻抗锯齿原图"，它的目标是**肉眼几乎看不出差别**。
扁平插画在 33 dB 已经是可印刷质量（项目实测白缝 0~6 个）。
**先确认用户要的是"更像原图"还是"更像矢量"**——这两者在扁平插画上会冲突。

## 附：本轮踩的工程坑（非算法）

| 坑 | 表现 | 解法 |
|---|---|---|
| Node 里 vendor 的 wasm 加载 | `fetch failed` | patch `globalThis.fetch`，`file://` 走 `fs.readFile` |
| PowerShell 传 JSON 给 node | 引号被吃掉，`JSON.parse` 报错 | options 走文件，不走命令行 |
| PowerShell heredoc | `python - <<'PY'` 解析失败 | 一律写成 .py 文件再跑 |
| PowerShell `Set-Content -Encoding utf8` 改 Python 源码 | 中文注释变成私用区字符，`invalid non-printable character` | 用编辑工具改，不用 shell 重写 |
| PIL `save('x.raw')` | `unknown file extension` | 用 `open(...,'wb').write(im.tobytes())` |
