## 三、当前管线顺序（v8.8）

```
preprocess（降采样→×2 上采样→去噪 8→保边平滑→量化→元素保护）
→ VTracer（colorPrecision 8 / layerDifference 16 / cutout / spline / simplify 1）
→ refine（默认关）
→ dropBackgroundLayer（必须早于 SVGO 与同色合并）
→ SVGO（仅「标准 SVG」模式）
→ snapFillColors（按模板，插画类开）
→ mergeSameColorPaths（merge=同色合并开关；容差 0.5；碎块 6px²；边缘平滑 1）
→ unifyEqualRadiiInSvg（仅合并开启且非 cutout）
→ snapAdjacentBoundaries（同上）
→ addStrokeCompensation（线宽 0.7 × 上采样倍数）
→ restoreProtectedColors / restoreBackgroundColor（fill 与 stroke 同步还原）
→ ensureSvgSize（width/height 与 viewBox 分离）
→ toLegacySvg（老软件模式；viewBox≠width 时包 scale）
```

## 六、本轮新增的负面结果（勿重复）

1. **共享边界联合简化**（原计划的 Phase 3 第一步）
   - 共享边界真实存在：bc ×2 输出 91.4% 锚点位置被 ≥2 子路径共用。
   - 但 VTracer 把每条共享边切成很多短段：仅 506 条可合并链，长度集中在 2–7 段。
   - 端点为固定、最小二乘三次贝塞尔合并（容差 0.8/1.5/2.5）：
     PSNR 34.79/34.77/34.76（不掉），节点 25.2k→24.4k/23.2k/22.3k（**只降 3–12%**），edgeCorr 不变。
   - 结论：**瓶颈不在共享边，而在 VTracer 每条轮廓的锚点密度/拟合方式**。该方案风险大、收益小，未合并进生产。
2. **VTracer `simplify` 2/3 不能降节点**：×2 下 25,247→23,154/23,002（−8%/−9%），PSNR 34.80→34.68/34.53。
3. **几何平滑/亚像素/联合优化**：仍按 `NEGATIVE_RESULTS.md` 的既有结论，不要重测。

已同步到 [`docs/NEGATIVE_RESULTS.md`](../../NEGATIVE_RESULTS.md) 的 N13。

## 七、已知风险与注意事项

- **×2 默认为质量优先**：路径/节点/耗时约 2–4 倍。若在 CorelDRAW 里觉得卡，把「描摹分辨率」改为**关闭**即回到 1×（质量约 33.3 dB）。
- 像素预算 8M：1600² 以上图像通常会自动跳过 ×2；这是防止引擎退化的安全线（3840² 实测会大面积白覆盖）。
- 部署需要 `CLOUDFLARE_API_TOKEN` + `CLOUDFLARE_ACCOUNT_ID`；**不要把 token 写入仓库**。
- 本机 wrangler 未持久登录，每次部署用环境变量临时注入。
