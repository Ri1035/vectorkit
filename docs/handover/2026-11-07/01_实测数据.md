## 3. 怎么读这些数

- **A vs B**：`polygon` 比 `spline` 高 0.41 dB，但段数是 3.2 倍、体积小 30%
  → **VTracer 的 spline 拟合是"拿精度换体积"的有效手段**，不是缺陷
- **B2 vs A**：多 2.7 倍段数只换来 0.46 dB → 自研拟合效率**不如引擎**
- **B2-e15 vs A**：1830 段换 32.03，还不如 spline 的 1493 段 32.88 → 同段数下**引擎更优**
- **C vs B2**：任何平滑 −1.35~1.65 dB
- **C-0 vs B2**：完全一致 → 平滑是唯一变量
- **D vs B2**：亚像素目标判定 81% 点"可移动"，联合优化后 −2.93 dB
