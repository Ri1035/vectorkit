## 1. VM 的算法定位

**不是"更好的描摹"，是"反问题求解"**：

```
把「矢量图 + 抗锯齿光栅化」建成可微生成模型
→ 求使生成图最接近输入位图的矢量参数（MAP 估计）
→ 离散阶段定拓扑/颜色，连续阶段用非线性共轭梯度定精确边界
```

对比 VTracer：颜色聚类 + 轮廓追踪 + 曲线拟合，**一次成型，无迭代优化**。

这就是为什么 VM 慢、准、节点少。

## 2. 轮廓平滑的四项能量（`0x495B00` / `0x494580` / `0x494840`）

设闭合轮廓点列 `p_0..p_{n-1}`，边长 `n_i = |p_{i+1} − p_i|`，目标点 `p̂`（来自分割/亚像素）。

```python
E = w_prior · Σ |(p_{i+1}−p_i)/n_i⁺ − (p_i−p_{i−1})/n_i⁻|²   # ① 弧长归一化二阶差分
  + w_len   · Σ sqrt(2 − 2·cosθ_i + 0.001)                   # ② L1 转角（|û−v̂|）
  + w_air   · ½Σ cross(p_i, p_{i+1})                         # ③ 气压（防塌缩）
  + Σ ρ(|p_i − p̂_i|)                                         # ④ 鲁棒数据项
```

### ② 是最关键的一项

`sqrt(2−2cosθ) = |û − v̂|`，两个单位切向量之差的**欧氏模**。

- 用 L2（`(1−cosθ)` 或平方）→ 90° 角要付平方级代价 → 被拉成圆弧
- 用 L1（模长）→ 90° 和一个 5° 抖动"单价"相同，但抖动是一串点、角是一个点 → **角留下、抖动消失**

**这是"高识别"的数学来源。**

### ④ 鲁棒数据项（IRLS）

```python
d = |p − p̂|
if d <= 0.7:  w = 0            # 死区：完全不动
else:         w = 2·(1 − 0.7/d)
grad += w · (p − p̂)
```

0.7 像素死区让分割边界的 1px 抖动**一个梯度都不产生**。

### ③ 气压项

`±½κ·rot90(p)`，κ 是**逐边**的量（`边长 × 权重`）。**不要写成全局面积项**——量级会失控
（本轮实测：全局面积项让能量 49000 vs 其它项几十，平滑把圆推走 12 px）。

## 3. 解析梯度（已验证，相对误差 < 1e-8）

```python
# ① prior: r_i = a_i − b_i，a_i=(p_{i+1}−p_i)/n_i，b_i=(p_i−p_{i−1})/n_{i−1}
g_j = 2·[ r_{j−1}/n_{j−1} − r_j/n_j − r_j/n_{j−1} + r_{j+1}/n_j ]

# ② angle: ∂E/∂u = −(v̂ − cosθ·û)/(|u|·sqrt(2−2cosθ+ε))
#          ∂E/∂v = −(û − cosθ·v̂)/(|v|·sqrt(2−2cosθ+ε))
#          散射: g_i = −du_i + du_{i−1} + dv_i − dv_{i+1}

# ③ air: g_i = ½·(y_{i+1} − y_{i−1}, x_{i−1} − x_{i+1})

# ④ data: g_i = w_i·(p_i − p̂_i)，w_i 见上
```

**两个必须注意的点**：
1. `n` 必须**固定**（在求解开始时算一次），不能每次能量计算重算——否则梯度与能量不一致，数值校验会差 40%
2. 边长 `n` 依赖 `p`，但 VM 的实现里 `n` 是预计算的（`0x494580` 里 `1/n` 是常量）

## 4. 共轭梯度求解（`0x4ADA10`）

```python
x = x0; g = grad(x); d = -g; knock = 0
for it in 1..max_iter:
    x_new, f_new = armijo(x, f, g, d, max_step=0.3)
    delta = f - f_new
    knock = knock+1 if delta <= 0 else 0
    if knock >= knock_out_count_down and it >= min_iter: break
    if it % iter_for_restart == 0: d = -grad(x)          # 重启（防共轭性丢失）
    else: beta = (g_new·g_new)/(g·g); d = -g_new + beta*d  # Fletcher–Reeves
```

**VM 的特色**：`num_blind_steps = 50` / `num_seeing_steps = 2` / `blind_blend_latest = 0.5`
——先"闭眼"沿方向走 50 步不看目标，再用 2 步实测决定接不接受（用来跳浅局部极小）。

## 5. 三阶段参数（配置实证）

| | phase 0（粗） | phase 1（精） | phase 2（收） |
|---|---|---|---|
| `max_iter` / `min_iter` | 30 / 10 | 200 / 50 | 200 / 20 |
| `length_penalty_weight` | **5.0** | 0.5 | 0.5 |
| `prior_strength` | 10 | 10 | 10 |
| `puncture_corners` | 0 | **1** | 0 |
| `rel_tol` / `abs_tol` | 1e-5 / 1e-5 | 同 | 同 |
| `max_step_size` | 0.3 | 0.3 | 0.3 |

**策略**：先强长度惩罚磨平（角也会被磨）→ 再降权重 + 开启"角点穿刺"把角找回来 → 收尾。

## 6. 自动参数公式（`FUN_0046b9a0`，`s ∈ 1..11`）

```
λ_pre = λ_initial = (13 − s) · 1e-4
λ_final           = 0.05 · 400^((12 − s)/11)
prior_strength[i] = base[i] · (top[i]/base[i])^((s−1)/11)
length_weight[i]  = base2[i] · (top2[i]/base2[i])^((s−1)/11)
```

阶梯表（`0xA21C40` 起）：

| 表 | base | top |
|---|---|---|
| prior（平滑启用） | `[0.05, 0.01, 0.45]` | `[10, 10, 10]` |
| length（启用） | `[0.25, 0.05, 0.005]` | `[10, 1, 1]` |

`s` 越小越激进。**10 组预设就是这条公式在 11 级阶梯上的采样**（实测 `s≈2` → λ_final≈10 = 照片低质量）。

## 7. 贝塞尔：VM 不是"拟合"，是"节点 + 手柄"

- 每个节点带左右两个手柄（`0x49E960` 取 4 个控制点）
- 手柄方向由相邻点切线决定（`0x47FE00/0x47FF00`），**角点用硬切线**（各自相邻边方向）
- `0x49FC80`（4330 字节）负责把相邻段的手柄**拉到共线**（C1 连续），对角点跳过
- 共线三点在 `1e-4` 叉积 + 投影检查下**直接合并成直线**（`0x47EFE0`）

**没有最小二乘、没有误差阈值**——所以别去找"拟合算法"，它是几何构造。
