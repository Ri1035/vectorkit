# VectorKit 视觉规范 · 粘土型态（Claymorphism）

> 本文件是 VectorKit 的界面唯一事实来源。改动 UI 前请先读这里，改完请同步更新。

## 一、设计语言定位

粘土型态像"捏出来的软胶积木"——靠圆润的球体感、厚实的边缘和糖果粉彩建立亲密、可信、可触摸的界面气质。

与相邻风格的差异：

| 风格 | 光照来源 | 背景约束 | 气质 |
|---|---|---|---|
| 扁平 Flat | 无 | 无 | 冷静、中性 |
| 新拟态 Neumorphism | 外阴影对（亮/暗） | **必须与背景同色** | 内敛、低对比 |
| 玻璃拟态 Glassmorphism | 模糊 + 透明 | 需复杂背景衬托 | 轻盈、科技 |
| **粘土型态 Claymorphism** | **双内阴影 + 偏移外阴影** | **任意背景色均可** | **亲和、玩具感** |

关键优势：粘土型态不依赖背景色，且天然带有"可点击"的暗示，适合工具类界面。

---

## 二、三大构成要素

### 1. 大圆角（Large Radius）

20–50px 的超大圆角制造"吹胀感"。

| 用途 | 令牌 | 值 |
|---|---|---|
| 大卡片 / 舞台 | `--r-2xl` | 32px |
| 卡片 / 面板 | `--r-xl` | 24px |
| 小卡 / 输入框 | `--r-lg` | 18px |
| 按钮 / 标签 | `--r-md` | 14px |
| 胶囊（按钮、徽章、标签栏） | `--r-pill` | 999px |
| 迷你元素（色块、滑块） | `--r-sm` | 10px |

> 移动端（<640px）整体下调约 25%，避免大圆角挤压内容。

### 2. 双内阴影（Dual Inner Shadows）

这是粘土感的核心，也是多数人漏掉的一步：

- **左上内高光**：`inset` 正值偏移 + 浅色 → 模拟顶部环境光打在球面上
- **右下内暗影**：`inset` 负值偏移 + 深色 → 给球体"收边"，锚定体积

缺了内阴影，大圆角色块只会显得扁平——**不能省**。

### 3. 偏移外阴影（Offset Outer Shadow）

方向性外阴影（非居中扩散），给元素"落地感"。糖果色元素使用**同色系**投影，而非灰黑：

```css
/* 紫色糖果按钮的投影是紫色，不是黑色 */
0 10px 24px rgba(167, 139, 250, .55)
```

## 三、配色令牌

### 浅色模式

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#EFEAF8` | 页面底色（淡紫灰） |
| `--bg-deep` | `#E4DDF3` | 舞台外框、凹槽底 |
| `--surface` | `#F8F5FD` | 卡片面 |
| `--surface-2` | `#F1ECFA` | 次级面、内陷区 |
| `--line` | `#E3DBF2` | 分隔线 |
| `--text` | `#2A2340` | 主文字（对 `--surface` 对比度 11.8:1） |
| `--text-2` | `#5D5478` | 次文字（5.6:1） |
| `--text-3` | `#8C84A6` | 辅助文字（仅用于非关键信息） |

**糖果色板**（强调、状态、图标底）：

| 名称 | 令牌 | 值 | 典型用途 |
|---|---|---|---|
| 紫 | `--c-violet` | `#A78BFA` | 主操作按钮、进度条 |
| 粉 | `--c-pink` | `#F9A8D4` | 成功态、结果高亮 |
| 蓝 | `--c-sky` | `#7DD3FC` | 信息、链接 |
| 绿 | `--c-mint` | `#86EFAC` | 完成态、节省比例 |
| 橙 | `--c-peach` | `#FDBA74` | 警告、加载中 |
| 黄 | `--c-lemon` | `#FDE68A` | 提示、缓存复用 |

### 深色模式（暖调，禁用纯黑）

| 令牌 | 值 |
|---|---|
| `--bg` | `#171327` |
| `--bg-deep` | `#120F1F` |
| `--surface` | `#221C36` |
| `--surface-2` | `#1B1630` |
| `--line` | `#322A4D` |
| `--text` | `#F1ECFB` |
| `--text-2` | `#B3AACB` |

深色模式三条硬规则：

1. 内高光强度降到 `rgba(255,255,255,.06)`（浅色模式是 `.55`），否则会发光溢出
2. 外阴影不透明度提高约 1.4 倍，否则元素"浮不起来"
3. 背景用暖调深紫，**不用纯黑**——纯黑会让粘土质感变成塑料质感

## 四、阴影令牌（完整公式）

```css
--clay-1:                      /* 最轻：小元素、胶囊 */
  0 4px 10px rgba(80, 60, 140, .10),
  inset 2px 2px 4px rgba(255,255,255,.55),
  inset -2px -2px 5px rgba(93, 72, 150, .10);

--clay-2:                      /* 默认：卡片、按钮 */
  0 10px 22px rgba(80, 60, 140, .13),
  inset 3px 3px 6px rgba(255,255,255,.60),
  inset -3px -3px 8px rgba(93, 72, 150, .12);

--clay-3:                      /* 最强：主按钮、舞台 */
  0 16px 34px rgba(80, 60, 140, .18),
  inset 4px 4px 8px rgba(255,255,255,.62),
  inset -4px -4px 10px rgba(93, 72, 150, .14);

--clay-pressed:                /* 按下 / 凹槽（输入框、进度槽） */
  inset 3px 3px 7px rgba(93, 72, 150, .16),
  inset -3px -3px 7px rgba(255,255,255,.55);

--clay-elevated:               /* 悬停 */
  0 22px 44px rgba(80, 60, 140, .20),
  inset 4px 4px 8px rgba(255,255,255,.66),
  inset -4px -4px 10px rgba(93, 72, 150, .13);
```

糖果色元素（主按钮、进度填充）用**同色投影**替换灰色外阴影：

```css
--clay-violet:
  0 10px 24px rgba(167,139,250,.50),
  0 4px 8px rgba(80,60,140,.12),
  inset 0 4px 8px rgba(255,255,255,.45),
  inset 0 -4px 8px rgba(70,50,120,.18);
```

## 五、布局与断点

沿用现有三档栅格，仅替换视觉皮肤：

| 断点 | 布局 | 关键变化 |
|---|---|---|
| **≥1081px** 桌面 | 双栏 `392px + 1fr`，间距 20px | 参数栏固定宽，预览区自适应 |
| **641–1080px** 平板 | 单栏，参数在上、预览在下 | 卡片间距收到 16px |
| **≤640px** 移动 | 单栏 + 底部标签栏 | 圆角降 25%，触控目标 ≥ 44px，底部留 `safe-area` 内边距 |

容器：`max-width: 1380px`，左右内边距 24px（移动 14px）。

## 六、组件规范

### 卡片

```css
.clay-card{
  background: var(--surface);
  border-radius: var(--r-xl);
  box-shadow: var(--clay-2);
  padding: 18px;
}
```

无边框（靠阴影塑形）。卡片标题：11.5px / 600 / 字距 .08em / 全大写 / `--text-3`。

### 按钮

| 类型 | 背景 | 阴影 | 用途 |
|---|---|---|---|
| 主按钮 | `--c-violet` 渐变 | `--clay-violet` | 开始转换 / 生成 / 优化 |
| 次按钮 | `--surface` | `--clay-1` | 下载、复制、辅助操作 |
| 幽灵按钮 | 透明 | 无（hover 时 `--clay-1`） | 文字级操作 |

主按钮为**胶囊形**（`--r-pill`），高度 ≥ 46px。

### 输入 / 下拉 / 滑块

输入类控件一律用**内陷**阴影（`--clay-pressed`）——这是粘土语言里"凹槽"的表达，与凸起的卡片形成对比。

滑块：轨道内陷 4px 高，滑块是**糖果色小球**（16px 圆 + `--clay-violet`），拖动时有轻微放大。

### 分段控件（引擎切换）

外槽内陷（`--clay-pressed`），选中项为凸起的小粘土块（`--clay-1` + 糖果色文字）。

### 标签栏

- 桌面：顶部胶囊容器（内陷槽），选中项凸起
- 移动：底部固定条，选中项用糖果紫色调 + 凸起

### 状态徽章（Chip）

胶囊 + `--clay-1`，底色为对应状态糖果色的低透明度版本：
- 加载中：橙（`--c-peach`）
- 就绪：绿（`--c-mint`）
- 错误：红（`#F87171`）

### 预览舞台

外框 `--clay-3` + `--r-2xl`；内部棋盘格区域用 `--clay-pressed` 形成"凹进去的展示坑"。

## 七、交互反馈规范

| 状态 | 表现 | 时长 |
|---|---|---|
| hover | `translateY(-2px)` + `--clay-elevated` | 180ms ease |
| active（按下） | `translateY(1px)` + `--clay-pressed`（视觉凹陷） | 80ms |
| focus | `outline: 2px solid var(--c-violet); outline-offset: 3px` | 即时 |

**可访问性硬要求**：

1. 文字对比度 ≥ 4.5:1（`--text-3` 只用于装饰性信息）
2. **必须保留可见的 focus 描边**——粘土阴影不足以指示键盘焦点
3. `prefers-reduced-motion: reduce` 时关闭所有位移与过渡
4. `prefers-contrast: more` 时压平阴影、改用实线描边

## 八、出图进度条

### 位置

位于**预览舞台头部下方、内容区上方**，横贯舞台整宽（左右各留 18px）。三个 Tab 的舞台各有一条，互不干扰。

```
┌─ 预览对比 ──────────── [下载 SVG] [复制源码] ─┐
├──────────────────────────────────────────────┤
│  ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░  转换中 62%          │  ← 进度条
├──────────────────────────────────────────────┤
│              内容区（对比预览）                │
└──────────────────────────────────────────────┘
```

### 样式

- **槽**：高 10px，胶囊圆角，`--clay-pressed` 内陷——像在粘土上压出的一道沟
- **填充**：糖果紫→粉渐变（`linear-gradient(90deg, #A78BFA, #F9A8D4)`），右端圆头，自身带轻微内高光，像一颗被挤出的软糖
- **文字**：右侧同行显示阶段名 + 百分比（12px，`--text-2`，等宽数字）
- **发光**：填充条带同色柔光（`box-shadow: 0 0 12px rgba(167,139,250,.45)`），强化"软胶被挤压"的观感

### 更新方式

VTracer / Potrace 的 wasm 调用是**同步阻塞**的，无法取得真实百分比。因此采用**阶段式推进**（诚实做法，不做假动画）：

| 阶段 | 权重 | 触发时机 |
|---|---|---|
| 准备 | 8% | 收集参数、拷贝像素数据 |
| 加载引擎 | 22% | 首次使用的引擎需下载 wasm |
| 图像分析 | 30% | 转换前处理 |
| 矢量化 | 80% | 引擎主转换 |
| SVG 优化 | 92% | SVGO 压缩 |
| 完成 | 100% | 结果落盘 |

进度用 `requestAnimationFrame` 平滑插值（每帧靠近目标值 18%），避免跳变。引擎真实耗时会被反映——转换慢时进度会在 80% 附近停留，而不是匀速跑到 99% 骗人。

### 完成后的状态表现

1. 填充条**冲到 100%** 并整体变为薄荷绿（`--c-mint`）
2. 同行文字变为 **`完成 · 328ms`**（等宽数字，显示真实耗时）
3. 停留 1.4 秒后**淡出**（opacity 300ms），舞台回归干净状态
4. 若中途出错：填充变红、文字显示错误摘要、**不自动隐藏**，直到用户下次操作

### 重置规则

- 切换 Tab 或更换输入文件时立即归零并隐藏
- 参数变更后重新转换时从 0 重新推进
- 命中结果缓存（参数未变）时，进度条走"准备 → 完成"的快速路径（约 200ms），并提示"已复用上次结果"

## 九、目标参考效果

改造完成后，界面应当呈现：

- 整体底色为淡紫灰，卡片像一块块**被捏圆的白紫色软胶**浮在上面
- 每个元素都能看出**光从左上打过来**（左上亮、右下暗）
- 按钮是**能被按下去的糖果**——悬停时微微抬起，按下时视觉凹陷
- 参数滑块像嵌在粘土里的**轨道和小球**
- 进度条像一条被挤出的**紫色软糖**，在粘土槽里向前生长
- 深色模式是**暖紫夜色**，不是冷灰黑，且粘土质感完整保留

与现有设计的差异：从"扁平现代"转为"圆润有体积"，但**信息密度和布局不变**——这是换皮而非改版，功能位置全部保持。
