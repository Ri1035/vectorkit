# 并列引擎（VectorCraft 机制）实施计划

> 状态：**进行中**（v5.9 起）　目标：缩小与 Vector Magic 的最后约 2 dB
> 参照：`github.com/storytold/vectorcraft` 的 `crates/trace/`（Apache-2.0，clean-room）
> 验收硬门槛：bc.png 1024² 下 **PSNR ≥ 现状 +1 dB**（现状最佳 34.49 dB → 目标 ≥35.5 dB）

---

## 一、为什么做这个（依据）

v5.1/v5.2 已用实测排除全部"局部/单参数"手段（颜色拟合中性、色阶更差、样条参数 ±0.13 dB、
分辨率已同源、逐点亚像素重定位 0 收益且长段上有害）。剩余唯一解释是**边界落在哪里**。

VectorCraft 的机制（Apache-2.0，可参照实现）：
1. **量化**：blend 像素归到它所夹的两个色之间；连续调图像先"色调内平滑、保留边缘"；
2. **去噪**：4-连通同色小块 < 阈值 → 并入最常见邻色；
3. **跟边界**：像素**裂缝**边连成闭环（外 CW / 孔 CCW → 两种填充规则都正确）；
4. **亚像素**：每条裂缝沿法线移动"跨越它的那一列像素"给出的 **覆盖率** 偏移；
   **同一条裂缝从两侧算出同一点** → 相邻区域天然共享曲线；
5. **拟合**：还原被模糊磨圆的角点、直段→直线、圆→正圆，其余用**尽可能少**的三次贝塞尔。

---

## 二、架构决策：并列新引擎，不改底层

- 该引擎是「**位图 → SVG**」的**纯函数**，输出标准 SVG →
  **SVGO / 后处理 / SVG→位图 / CMYK EPS / DXF / 批量 / UI 全部原样复用**；
- 接入方式与当初接 ImageTracer 同构：**只在 `loadEngine` / `ENGINES` 槽位 / `vectorize()`
  / `SCHEMA`+`ADV` / 引擎按钮**五处新增分支，**既有分支零修改**；
- 默认引擎仍为 VTracer，效果不好直接换引擎即可，**零风险回退**；
- **不做独立 HTML 页面**（会产生两套 UI/预设/导出设置 —— 之前踩过的坑）。

---

## 三、分阶段（两次交付）

### P0 最小原型（目标 3–4 天）—— 只验证"几何能不能赢"
| 步骤 | 内容 | 产出 |
|---|---|---|
| P0-1 | 量化器（中位切割 + 最近色归属） | `labels: Int32Array` |
| P0-2 | 4-连通同色小块去噪（并入最常见邻色） | 干净的标签图 |
| P0-3 | 裂缝提取（水平/垂直相邻异色像素之间） | 裂缝段 + 法线方向 |
| P0-4 | **覆盖率 α**：`α = ((C−C_B)·(C_A−C_B)) / |C_A−C_B|²`，边界位置 `= 裂缝坐标 + (α − 0.5)` | 亚像素裂缝点 |
| P0-5 | 裂缝连成闭环（外 CW / 孔 CCW） | 折线轮廓 |
| P0-6 | 输出折线 SVG 并测 PSNR | **是否 ≥35.5 dB 的结论** |

> **P0 的意义**：折线版节点数会很多（约等于边界像素数），但它代表**纯几何阶段的上限**。
> 若连折线版都打不过 34.49 dB，说明机制在我们的场景无效 → **立即止损**；
> 若能超过，则剩余工作只是"用更少节点达到同样精度"的拟合问题。

### P1 完整拟合（原型达标后再做，约 4–5 天）
| 步骤 | 内容 |
|---|---|
| P1-1 | 交汇处（三区域相遇）**切段**，每段独立拟合 |
| P1-2 | **两侧同算法**：保证相邻区域共享同一条曲线 |
| P1-3 | 角点还原、直段→直线、圆轮廓→正圆 |
| P1-4 | 其余段用**尽可能少**的三次贝塞尔拟合（容差可调） |
| P1-5 | 参数 UI + 预设 + 接进引擎框架 |

## 四、风险与对策

| 风险 | 对策 |
|---|---|
| 折线版节点数巨大（内存/文件） | P0 只用于**测 PSNR**，不作为交付产物 |
| 拟合质量不足（节点不够少） | P0 先验证几何上限；若上限够，P1 逐步逼近 |
| 性能（2048² 纯 JS） | 分块 + 整数运算；必要时先降采样再描摹（复用现有「描摹分辨率」档） |
| 与 VTracer 参数体系纠缠 | **独立参数体系**，不复用去噪/simplify/cutout |

## 五、里程碑与停损

- **M1（P0 完成）**：给出"折线版 PSNR"数字 → **低于 34.49 就停**，如实记录失败原因；
- **M2（P1 拟合完成）**：节点数与 PSNR 双达标才考虑设为可选默认档。
