# 矢量输出平滑方案（v2.2 提案）

> 状态：**待确认**（本文档为方案，未动手改代码）
> 目标：**细节保留 + 减少矢量锯齿**，EPS 与 SVG 同时受益（同一 SVG 源，一处修复两处生效）

---

## 一、锯齿根因诊断（代码级证据）

当前后处理管线里，曲线路径的最终形态在 `merge-paths.js` 的 `resampleSimplify()`：

```
原始曲线路径（VTracer spline 输出）
  → 每段采样 5 点
  → D-P 简化（容差控制）
  → p.add(new Point(x, y))          ← 【根因】加的是无句柄的点 → 重建为纯折线
  → roundShallowCorners()           ← 只给「偏离直线 < 28°/42°」的极浅转角加句柄
```

**问题**：圆弧被简化成多边形后，只有非常浅的转角被曲线化，**中等曲率的弧线区域全部保持直线段**。
简化越狠（容差越大、节点越少），每段直线越长，锯齿感越强。这就是「细节保留（节点少了）但锯齿明显」的直接原因。

次要来源（影响小，暂不处理）：
- 源图边缘抗锯齿像素产生的微小台阶（预处理可缓解，已有开关）
- VTracer `cornerThreshold=60`：60° 以下的偏转在引擎内就保留尖角

## 二、方案：全曲线拟合（硬边保护）

**一句话**：把重建阶段的「折线 + 浅转角曲线化」升级为「**全曲线拟合 + 锐角保护**」。

### 拟合算法（Catmull-Rom 过点切线句柄）

对简化后的每个锚点，计算入方向与出方向的偏转角 `turn`：

```
turn ≤ hardProtect（55°~65°）  → 锐角/直角：句柄清零，保持尖角（吊牌的直角、锐角不受影响）
turn >  hardProtect            → 平滑区：按切线方向生成对称句柄
                                  句柄长度 = min(前点距, 后点距) × k
```

- Catmull-Rom 的句柄由**相邻点切线**决定，曲线**精确过每个锚点**——形状偏差近似为 0，细节不丢
- G1 连续（相邻曲线段切线衔接），无折痕
- 与现有 `roundShallowCorners` 的关系：**语义反转**（现在是"浅转角才曲线化"，方案是"非锐角全部曲线化"），替换该步骤

### 档位映射

| 平滑档位 | 行为 |
|---|---|
| 轻度（1） | 保持现状：近直线转直 + 折线去抖（零变形，给需要完全保真的场景） |
| 标准（2） | 重采样简化 + **全曲线拟合**（k=0.35，锐角保护阈值 65°） |
| 强化（3） | 重采样简化 + **全曲线拟合**（k=0.45，锐角保护阈值 55°，曲线更饱满） |

## 三、辅助手段（可选项，你拍板是否一起做）

**B. 小图 2× 上采样预处理**：源图小于 800px 时先放大 2 倍再描摹——抗锯齿边缘的台阶宽度减半，
描摹输出天然更平滑。代价：节点数约 +40~60%（可用「细节保留度」补偿）、处理时间 ×3~4（本地 wasm，可接受）。
做成预处理面板的一个开关「小图自动上采样」，默认开。

**不做的事**（说明理由）：
- 不动 VTracer `cornerThreshold` 默认值（60）——会影响全部 5 个预设的既有行为，全曲线拟合已覆盖该收益
- 不追 AI 矢量化路线（Vector Magic 官方都已转向 Vectorizer.AI）——纯本地隐私+免费是 vectorkit 的定位

## 四、验证方法（实施后跑给你看）

合成测试图（正圆 + 波浪线 + 直角方块 + 噪点边缘），三组指标：

1. **MAE**（形状保真）：方案前后应基本持平（Catmull-Rom 过锚点，偏差≈0）
2. **节点数**：不高于现状（拟合不加节点）
3. **锯齿指数**（新增指标）：相邻边方向变化率的标准差——平滑曲线的方向变化平缓，锯齿呈高频振荡，数值可量化对比
4. **放大 4× 目检**：圆与波浪线的边缘对比截图（EPS/SVG 各一份）
